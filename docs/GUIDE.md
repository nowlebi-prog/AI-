# Hub 사용 가이드

## 1. 한눈에 보기

### 메뉴 지도

| 메뉴 | 언제 | 여기서 하는 일 | 이어지는 곳 |
|---|---|---|---|
| **오늘** | 아침, 수시로 | 전체 프로젝트의 할 일 보드, 빠른 추가, 인박스 미리보기, 브리핑 복사 | 할 일 `⋯` → AI에게 맡기기 · 🌙 하루 마감 |
| **대시보드** | 주간 점검 | **현황**: 분야별 카드, 14일 마감 그래프, 프로젝트 진행도(%) · **월간 달력**: 한 달 보기, 분야 필터 | 분야 카드 → 오늘(그 분야만) · 달력 항목 → 그 할 일 · 날짜의 `＋` → 그 날짜로 빠른 추가 |
| **프로젝트** | 작업 시작 전 | 카드(목표·타깃·단계…), 진행도, 할 일, 결정, 레퍼런스, 세션 기록, 마지막 위치, 브리핑 | 🤖 AI에게 맡기기 · 레퍼런스 |
| **레퍼런스** | 좋은 사이트를 봤을 때 | 링크 저장(제목·썸네일·카테고리 자동), 검색, 태그, 프로젝트 연결 | 프로젝트 화면 · 전체 검색 · AI가 찾기/저장 |
| **AI 실행** | AI에게 일을 맡길 때 | 어떤 AI·모델로 할지 추천 → 앱에서 열기 또는 API로 실행 | 결과의 `[Hub 메모]` → 기록·인박스 |
| **인박스** | AI와 대화한 뒤 | AI 제안 승인·수정·거절, 바로 반영된 변경 되돌리기 | 승인하면 할 일·결정·프로젝트에 반영 |
| **붙여넣기** | MCP가 없는 AI와 대화한 뒤 | 대화 끝의 `[Hub 메모]`를 붙여 넣어 반영 | 인박스 |
| **하루 마감** | 저녁 (오늘 화면의 🌙 버튼) | 오늘 요약 → 못 끝낸 일 넘기기 → 파일 정리 → 한 줄 회고 | Grok Bot 요청문 · 휴지통 명령 |
| **검색** | 언제든 (`/`) | 프로젝트·결정·할 일·레퍼런스·AI 기록 한 번에 | 각 항목 |
| **설정** | 처음 한 번 | 프로필, AI 연결, AI 실행, 자동화, 캘린더, 토큰, 데이터(백업·노션 가져오기) | — |

### 기능이 이어지는 방식

1. **들어오는 길** — 빠른 추가(바로 들어가요) · AI 제안(MCP) · `[Hub 메모]` 붙여넣기 · AI 실행 결과 → 제안은 **인박스**에서 승인하면 할 일·결정이 돼요.
2. **보는 곳** — 할 일은 오늘 · 대시보드 · 월간 달력 · 폰 캘린더(구독)에 한꺼번에 보여요. 한 곳에서 고치면 전부 바뀌어요.
3. **맡기는 길** — 할 일 `⋯ → 🤖 AI에게 맡기기` → AI 실행이 AI·모델을 추천 → 결과가 다시 1번으로 들어와요.
4. **AI가 읽는 것** — 새 창에서 AI는 프로필 + 프로젝트 카드 + 결정 + 할 일 + 마지막 위치를 브리핑으로 받아요 (L 크기면 레퍼런스까지).
5. **마무리** — 하루 마감에서 못 끝낸 일을 넘기고, 한 줄 회고는 세션 기록으로 남아 다음 브리핑에 들어가요.
6. **레퍼런스** — 링크 붙여넣기나 AI 저장 → 프로젝트 화면 · 검색 · 브리핑에서 다시 찾아요.

- **원본은 Hub 하나**예요. AI끼리 서로 덮어쓰지 않고, 모두 Hub를 봐요.
- AI가 올린 건 기본적으로 **제안**이라 인박스에서 승인해야 들어가요. 내가 AI에게 **직접 시킨 것**("추가해 줘")은 바로 들어가고, 뭐든 **되돌릴 수** 있어요.

## 2. 처음 설정

1. **배포하고 로그인** — AI가 접속하려면 인터넷에서 열리는 HTTPS 주소가 필요해요 ([README의 배포](../README.md#배포-ai-연결에-필요)). `HUB_PASSWORD`로 로그인해요.
2. **설정 → 프로필** — 이름, 소개, 작업 선호(예: "답은 한국어로 짧게, 선택지는 표로"). 모든 브리핑 맨 위에 들어가서 AI가 나를 알게 돼요.
3. **프로젝트 만들기** — 프로젝트 → 이름·한 줄 소개·**분야**(개발·기획·디자인·마케팅·문서·PPT·운영) → 만들기. 상세 화면의 **프로젝트 카드**에 목표·타깃·현재 단계·제약·작업 범위를 채워 두면 AI 답이 훨씬 정확해져요.
   - 노션에서 옮기기: 설정 → 데이터 → **노션·텍스트 가져오기** → 페이지 주소(또는 복사한 내용) → 가져온 문서의 **AI에게 정리 맡기기** 문구를 연결된 AI에게 보내면, AI가 읽고 프로젝트·결정·할 일로 나눠 제안해요.
4. **AI 연결** — [3장](#3-ai-연결).
5. **캘린더 구독** — 설정 → 캘린더 → 구독 주소 만들기 → 구글 캘린더(다른 캘린더 ＋ → URL로 추가)나 애플 캘린더(새로운 캘린더 구독)에 넣어요. 마감이 있는 할 일이 폰 캘린더에 뜨고, 반복 할 일은 반복 일정으로 보여요.
6. **앱으로 설치** — [8장](#8-단축키앱-설치).
7. (선택) **자동화** — 설정 → 자동화
   - *직접 시킨 변경은 바로 반영*: 기본으로 켜져 있어요
   - *종류별 자동 승인*: 믿을 수 있는 종류만 켜세요 (예: 할 일 변경)
   - *하루 시작 시각*: 새벽까지 일하면 3시 등으로 (그 전까지는 '오늘'을 전날로 쳐요)
   - *하루 마감 알림*: 이 시각이 지나면 오늘 화면에 마감 안내가 떠요 (기본 18시)
8. (선택) **AI 실행 키** — 서버 `.env`에 `TYPESAFE_API_KEY`(Jev 추천), `OPENAI_API_KEY`·`ANTHROPIC_API_KEY`·`XAI_API_KEY`(Hub 안에서 바로 실행)를 넣어요. 없어도 추천(규칙)과 앱에서 열기는 돼요.

## 3. AI 연결

MCP 주소는 **설정 → AI 연결**에 있어요 (`https://내주소/mcp`, 끝에 `/` 없이).

| AI | 연결 방법 |
|---|---|
| **Claude** (데스크톱·웹) | 설정 → 커넥터 → 커스텀 커넥터 추가 → 이름 `Hub`, URL에 MCP 주소 → Hub 로그인 → 허용 |
| **ChatGPT** (Pro) | 웹(chatgpt.com) 설정 → Apps & Connectors → Advanced settings → Developer mode 켜기 → 커넥터 만들기(URL, 인증 OAuth) → Hub에서 허용. 데스크톱 앱에도 동기화돼요. 대화할 때 Developer mode에서 Hub를 켜세요 |
| **Grok** | grok.com → 커넥터 → New Connector → Custom → MCP 주소 → OAuth 로그인·허용 |
| **Grok Bot** | 설정 → 토큰에서 `Grok Bot` 개인 토큰 만들기 → Grok Bot Settings → Plugins → 커스텀 MCP 서버 → 주소 + 헤더 `Authorization: Bearer (토큰)` |
| **Meta Muse** | 설정 → 토큰에서 `Muse` 개인 토큰 만들기 → Muse에게 "Streamable HTTP MCP 서버 (주소)에 헤더 Authorization: Bearer (토큰)으로 연결하는 스킬을 만들어 저장해 줘" |

**연결한 다음 꼭 할 것**: 설정 → AI 연결 아래의 **AI 지침 문구**를 복사해서 각 AI의 커스텀 지침(맞춤 설정, 프로젝트 지침)에 한 번 넣어 두세요. 그러면 AI가 알아서 브리핑을 읽고, 결정·할 일을 제안하고, 대화 끝에 기록을 남겨요.

- **연결 확인**: 설정 → MCP 호출 기록에 그 AI의 호출이 보이면 연결된 거예요. 연결된 앱 목록에서 이름을 바꾸면 기록의 출처 이름도 바뀌어요.
- **쓰기가 막힌 AI**(요금제·정책에 따라 ChatGPT에서 생길 수 있어요): 브리핑은 MCP로 받고, 대화 끝에 받은 `[Hub 메모]`를 **붙여넣기**로 반영하면 돼요.
- **MCP가 아예 없는 곳**: 오늘 화면이나 프로젝트 화면의 **브리핑 복사**를 대화 처음에 붙여 넣으세요. 복사한 브리핑에는 "끝날 때 `[Hub 메모]`로 정리해 달라"는 안내가 들어 있어요.

## 4. 하루 흐름

### 아침 (5분)

1. **오늘** — 위에서부터 봐요: 지난 마감 → 오늘 마감 → 진행 중 → 7일 안. `✓`로 완료, `⋯ → 미루기`로 날짜 옮기기.
2. **인박스 배지**가 있으면 밤사이 AI가 올린 제안을 승인해요 (오늘 화면 오른쪽에서도 바로 승인할 수 있어요).
3. 주 초에는 **대시보드 → 월간 달력**으로 이번 달 분야별·프로젝트별 진행도를 확인해요.

### 일하는 중

- **떠오르면 바로 빠른 추가** (`n`): `브랜드X 상세페이지 시안 금요일까지 #디자인 !` → 프로젝트·분야·마감·긴급을 알아서 읽어요. 입력하는 동안 아래에 미리보기가 떠요.
- **AI와 대화**: MCP가 연결된 AI에서 "브랜드X 이어서 하자"라고만 하면 AI가 브리핑을 읽고 시작해요. 끝날 때 "정리해서 Hub에 남겨 줘" → 요약과 **마지막 위치**가 저장되고, 결정·할 일은 인박스로 와요.
- **AI에게 맡기기**: 할 일 `⋯ → 🤖 AI에게 맡기기` (또는 AI 실행 메뉴) → 추천(예: 코드 → Claude, 최신 정보 → Grok) → **앱에서 열기**(프롬프트가 채워진 새 대화) 또는 **API로 실행**.
- **좋은 사이트를 보면**: 레퍼런스에 링크만 붙여 넣으면 제목·설명·카테고리가 채워져요. AI에게 "이 링크 Hub 레퍼런스에 저장해 줘"라고 해도 돼요.

### 저녁 (5분) — 🌙 하루 마감

오늘 화면의 **🌙 하루 마감** 버튼 (설정한 시각이 지나면 안내도 떠요).

1. **오늘 한 일** — 완료한 일, 정한 것, AI와 한 일이 모여 있어요.
2. **못 끝낸 일** — 체크한 것을 **내일로** 또는 **다음 주 월요일로** 한 번에 넘겨요.
3. **파일 정리 — 남길 것만 체크**
   - *Hub에 오늘 저장한 것*(레퍼런스·가져온 문서·AI 실행 기록): 필요 없는 것의 체크를 풀고 **체크 안 한 것 Hub에서 삭제**.
   - *내 컴퓨터 파일*: **오늘 생긴 파일 목록 가져오기**의 명령을 복사해 터미널(Mac)이나 PowerShell(Windows)에 붙여 넣으면, 다운로드·바탕화면·문서 폴더에서 오늘 생기거나 바뀐 파일 목록이 클립보드에 복사돼요(읽기만 해요) → Hub에 붙여 넣고 **목록에 추가** → **남길 파일만 체크** → **정리 목록 만들기**.
   - 그러면 **Grok Bot에게 보낼 요청문**이 만들어져요. **요청문 복사** → Grok Bot에게 보내면 돼요. Grok Bot이 Hub에 연결돼 있으면 짧은 요청문만 보내도 돼요.
   - Grok Bot이 내 PC 파일에 닿지 못하면 **내 컴퓨터에서 직접 휴지통으로 옮기기** 명령을 붙여 넣어 실행해요. 영구 삭제가 아니라 **휴지통으로** 옮겨서 되살릴 수 있어요.
4. **마감** — 한 줄 회고(잘된 것, 막힌 것, 내일 먼저 할 것)를 쓰고 **하루 마감하기**. 회고는 세션 기록으로 남아 AI 브리핑·주간 요약에도 들어가요.

> Hub는 내 컴퓨터 파일을 직접 보거나 지우지 않아요. 목록은 내가 붙여 넣거나, 파일에 접근할 수 있는 AI(예: 파일 접근을 연결한 Claude 데스크톱)가 `submit_files`로 보내요.

## 5. 메뉴별 사용법

### 오늘

- **구역**: 지난 마감 · 오늘 마감 · 진행 중 · 7일 안 · 대기 중 · 나중에(마감이 7일 뒤) · 마감 없음 · 오늘 완료(접힘). 위의 분야 버튼으로 한 분야만 볼 수 있어요.
- **할 일 한 줄**: `✓` 완료/되돌리기 · `시작`/`멈춤`(진행 중 표시) · `⋯` 메뉴
  - **미루기**: 오늘 · 내일 · 다음 주 · 마감 없음
  - **대기**: "피드백 기다림"처럼 이유를 적으면 대기 중 구역으로 가요 (지난 마감에 섞이지 않아요)
  - **🤖 AI에게 맡기기**: 제목·메모를 채운 채로 AI 실행으로
  - **편집**: 제목·프로젝트·분야·우선순위·마감·**반복**·메모
  - **삭제**
- **반복 할 일**: 완료하면 다음 차례가 자동으로 생기고, 완료를 취소하면 그 다음 차례도 사라져요.
- **여러 개 한 번에 추가**: AI가 준 체크리스트를 그대로 붙여 넣어도 돼요 (`-`, `1.`, `[ ]` 같은 앞머리는 떼요). 프로젝트를 고르면 줄마다 적용돼요.
- **오른쪽**: 인박스 미리보기(바로 승인·거절), AI가 바로 반영한 변경(지난 24시간), 브리핑 복사(전체 S·M, 지난 7일 요약, 프로젝트별), 최근 AI 세션.

### 대시보드

- **현황**: 분야별 카드(열린 일·지난 마감·7일 안·진행 중·대기·7일 완료, 누르면 오늘 화면을 그 분야로) → 다가오는 마감 14일 그래프 → 분야별 프로젝트 목록(다음 할 일, 마지막 위치, 진행도 %) → 프로젝트×분야 표.
- **월간 달력**: 노션 캘린더처럼 한 달을 봐요. `‹ 오늘 ›`로 달 이동, 위의 분야 버튼으로 거르기, 오른쪽 **이번 달 진행도**(분야별)와 **프로젝트 진행도**를 누르면 그것만 보여요. 항목을 누르면 그 할 일로, 날짜의 `＋`를 누르면 그 날짜가 채워진 빠른 추가로 가요.
- **프로젝트 진행도(%)** = 그 프로젝트의 할 일 중 완료한 비율 (계속 생기는 반복 할 일은 빼요).
- **이번 달 진행도** = 이번 달에 마감인 할 일 중 완료한 비율 (분야별로도 보여요).

### 프로젝트

- 목록: 분야별로 거르기, 진행도 막대, 열린 할 일 수.
- 상세: **브리핑**(S/M/L 복사) · **마지막 위치**(다음에 이어서 할 지점 한 줄) · **할 일** · **결정**(이유 포함, 바뀐 결정은 대체 이력으로 남아요) · **레퍼런스** · **세션 기록** · **프로젝트 카드**.
- 위의 **🤖 AI에게 맡기기**를 누르면 이 프로젝트가 골라진 채로 AI 실행이 열려요.
- 카드가 30일 넘게 안 바뀌면 브리핑에 ⚠️가 붙어요. 가끔 현재 단계를 고쳐 주세요.

### 레퍼런스

- **링크 붙여넣기** → 제목·설명·썸네일을 읽고 카테고리(디자인·개발·마케팅·기획·문서·PPT·영감·도구·기타)를 추천해요. 카테고리·메모("어디가 좋았는지, 어디에 쓸지")·태그·프로젝트를 붙일 수 있어요.
- **찾기**: 기억나는 단어로(제목·메모·태그·주소), 카테고리·태그를 눌러 거르기. 같은 링크를 또 넣으면 새로 만들지 않고 합쳐요.
- **여러 개 한 번에**: 한 줄에 링크 하나.
- AI에게 "그때 본 비건 패키지 사이트 찾아 줘"라고 하면 AI가 `find_references`로 찾아요.

### AI 실행

1. 할 일을 적고 **추천 받기** (프로젝트는 자동으로 찾거나 직접 골라요).
2. 추천 카드: 종류(개발·코딩, 글·카피, 최신 정보·리서치, 기획·전략, 분석·긴 문서, 이미지·디자인, 대신 처리, 간단한 질문), 판단 방식(**Jev 판단** 또는 규칙 판단)과 확신 %, 참고(웹 검색 켜기, Thinking 모드 권장 등).
3. 추천 AI와 대안 중에 골라서
   - **앱에서 열기**: 새 탭에서 그 AI가 프롬프트가 채워진 채로 열려요. 프롬프트가 길거나 Muse처럼 채우기를 못 하면 **복사해 두니 붙여넣기**만 하세요. Hub가 연결된 AI에는 "Hub에서 확인해 줘"라는 짧은 요청만 보내요.
   - **API로 실행**: 키가 있으면 Hub가 바로 실행하고 결과를 보여 줘요. 결과의 `[Hub 메모]`는 자동으로 기록되고 결정·할 일은 인박스로 가요.
4. 앱에서 연 대화는 끝나면 AI가 기록하거나(연결된 경우), 마지막의 `[Hub 메모]`를 **붙여넣기** 하세요.

- **추천표 바꾸기**: 설정 → AI 실행 → 종류별 추천 AI·모델·대안. 새 모델이 나오면 여기서 모델 이름만 바꾸면 돼요.
- 기본 추천: 개발·기획·분석 → Claude, 글·이미지·간단한 질문 → ChatGPT, 최신 정보 → Grok, 대신 처리 → Muse. 이미지와 대신 처리는 앱에서만 돼요.

### 인박스

- AI가 올린 제안이 프로젝트별로 모여요: **승인** · 고쳐서 **이대로 승인** · 거절 · **이 프로젝트 모두 승인** · **모두 승인**.
- 같은 할 일·결정이 이미 있으면 AI 제안을 막아서 중복이 생기지 않아요.
- 아래 **변경 기록**: AI에게 직접 시켜서 바로 반영된 것, 자동 승인된 것, 세션 기록이 보여요. 잘못 들어갔으면 **되돌리기**.

### 붙여넣기

MCP를 못 쓰거나 쓰기가 막힌 AI의 대화 끝에 나온 `[Hub 메모]`를 붙여 넣고 **반영하기**. 요약·마지막 위치는 바로 저장되고, 결정·할 일은 인박스로 가요. AI가 형식을 조금 바꿔 써도(제목, 목록, 이모지, 비슷한 말) 읽어요. 메모가 없으면 **메모 없이 세션 기록으로 저장**할 수 있어요.

### 검색

위의 검색창이나 `/`. 프로젝트·결정·할 일·레퍼런스·AI 기록·가져온 문서를 한 번에 찾아요. 여러 단어를 넣으면 모두 들어간 것만 찾아요.

### 설정

프로필 · AI 연결(주소, AI별 방법, 지침 문구) · AI 실행(키 상태, 추천표, 앱 주소) · 자동화 · 캘린더 구독 · 개인 토큰 · 연결된 앱 · MCP 호출 기록 · 데이터(백업, 노션·텍스트 가져오기, 모든 기기 로그아웃).

## 6. 입력 규칙

### 빠른 추가

| 넣는 것 | 쓰는 법 | 예 |
|---|---|---|
| 프로젝트 | 이름을 그냥 쓰거나 `@이름` (앞부분만 써도 돼요) | `브랜드X 로고 시안`, `@예약 API 설계` |
| 분야 | `#개발` `#기획` `#디자인` `#마케팅` `#문서`(`#PPT`) `#운영` `#기타` | `제안서 #PPT` |
| 긴급 | `!` 또는 `긴급`, `급함` → 우선순위 높음 | `계산서 발행 !` |
| 마감 | 오늘·내일·모레·글피 / 금요일 / 이번 주 금·다음 주 월(담주·차주) / 이번 주·다음 주(금요일로) / 10/3·10월 3일·2026-10-03 / 3일 후 / 주말 / 월말. 뒤에 `까지`·`안에`·`마감`을 붙여도 돼요 | `목업 다음 주 수요일까지` |
| 반복 | 매일 · 평일마다 · 매주 월 · 매주 월·수 · 매월 10일 · 매월 말일 | `주간 리포트 매주 월` |

- 분야를 안 쓰면 내용으로 짐작해요 (견적·계산서·미팅 → 운영, 시안·로고·배너 → 디자인, PPT·제안서 → 문서·PPT 등).
- 반복만 쓰고 마감을 안 쓰면 첫 차례 날짜가 마감이 돼요.

### `[Hub 메모]` 형식

AI가 대화 끝에 이렇게 정리해 주면 붙여넣기로 한 번에 반영돼요. 해당 없는 줄은 빼도 돼요.

```
[Hub 메모]
프로젝트: 브랜드X
요약: 로고 방향을 B안으로 정했다. 상세페이지 구성도 논의했다.
결정: 로고는 B안 | 이유: 타깃 선호 | 대체: D3
할 일: 상세페이지 시안 3종 | 디자인 | 2026-10-03
완료: T5, T7
위치: 시안 2까지 완료, 3번 시안 컬러 고민 중
[/Hub 메모]
```

- 할 일의 분야와 마감은 순서 상관없이 `|`로 이어 써요. 마감은 `금요일`, `내일`처럼 써도 돼요.
- `대체: D3`는 "예전 결정 D3를 이 결정으로 바꾼다"는 뜻이에요.

### 번호 규칙

P=프로젝트, D=결정, T=할 일, L=세션 기록, R=레퍼런스, I=가져온 문서. AI에게 "T12 완료 처리해 줘"처럼 번호로 말할 수 있어요.

## 7. AI에게 이렇게 말하면 돼요

MCP로 연결되고 지침 문구를 넣어 둔 AI 기준이에요.

| 이렇게 말하면 | AI가 하는 일 |
|---|---|
| "브랜드X 이어서 하자" | 브리핑을 읽고 마지막 위치부터 이어가요 (`get_brief`) |
| "이번 주에 뭐 했는지 정리해 줘" | 최근 완료·결정·세션을 모아 정리 (`recent_activity`) |
| "로고 시안 금요일까지 할 일로 추가해 줘" | 바로 추가 (`propose_task`, 직접 시킴) |
| "T12 완료 처리해 줘" | 바로 완료 |
| "이걸로 결정하자, Hub에 남겨 줘" | 결정 기록 (`propose_decision`) |
| (스스로 정리한 결정·할 일) | 인박스에 제안 → 내가 승인 |
| "이 링크 레퍼런스에 저장해 줘, 디자인으로" | 레퍼런스 저장 (`save_reference`) |
| "전에 본 예약 UI 사이트 찾아 줘" | 레퍼런스 검색 (`find_references`) |
| "오늘 대화 정리해서 Hub에 남겨 줘" | 요약·마지막 위치 저장 + 결정·할 일 제안 (`log_session`) |
| "새 프로젝트로 만들어 줘" | 카드·결정·할 일을 묶어 한 번에 제안 (`propose_project`) |
| (파일에 접근하는 AI) "오늘 받은 파일 목록 Hub에 올려 줘" | 하루 마감 화면으로 목록 전송 (`submit_files`) |
| (Grok Bot) "Hub에서 오늘 파일 정리 목록 받아서 지울 것만 휴지통으로" | 목록 확인 후 실행 (`get_file_cleanup`) |

## 9. 데이터·백업·되돌리기

- 모든 데이터는 SQLite 파일 하나(`data/hub.db`)에 있어요.
- **매일 자동 백업**: `data/backups/hub-날짜.db`로 7개까지 보관해요. 설정 → 데이터에서 내려받을 수 있고, **지금 백업 다운로드**도 있어요.
- **복원**: Hub를 멈추고 `hub.db`를 백업 파일로 바꾼 뒤 다시 시작해요.
- **되돌리기**: AI가 바로 반영한 것(직접 시킨 변경, 자동 승인, 레퍼런스 저장, 세션 기록)은 인박스 → 변경 기록에서 되돌려요.
- **로그인**: 30일 유지되고 쓰는 동안 자동으로 연장돼요. 기기를 잃어버렸으면 설정 → 데이터 → **모든 기기 로그아웃**.
- **토큰 관리**: 안 쓰는 개인 토큰은 폐기하고, 연결된 앱은 연결 끊기로 정리해요.

## 10. 문제 해결

| 증상 | 해결 |
|---|---|
| AI가 Hub에 연결되지 않아요 | HTTPS 주소로 배포했는지, `HUB_PUBLIC_URL`이 그 주소인지, MCP 주소 끝에 `/`가 없는지 확인하세요. 설정 → MCP 호출 기록에 실패 이유가 남아요 |
| ChatGPT에서 제안(쓰기)이 막혀요 | 요금제·정책에 따라 쓰기 도구가 막힐 수 있어요. 브리핑은 MCP로 받고, 끝에 `[Hub 메모]`를 받아 **붙여넣기** 하세요 |
| Muse가 연결 스킬을 못 만들어요 | 브리핑 복사로 시작하고, 끝에 `[Hub 메모]`를 받아 붙여넣기 하세요. AI 실행의 "Muse 앱에서 열기"는 프롬프트를 복사해 두고 Muse를 열어요 |
| Grok Bot이 내 파일을 못 지워요 | Grok Bot은 xAI 클라우드에서 동작해서 내 PC에 닿지 못할 수 있어요. 하루 마감 화면의 **휴지통 명령**을 직접 실행하세요 |
| 파일 목록 명령을 실행해도 비어 있어요 | Mac은 처음에 폴더 접근 허용 창이 떠요. 거절했다면 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 터미널을 허용하세요. 다른 폴더도 보려면 명령의 폴더 목록에 추가하면 돼요 |
| 새벽에 한 일이 다음 날로 잡혀요 | 설정 → 자동화 → **하루 시작 시각**을 새벽 3시 등으로 |
| AI가 추가한 할 일이 안 보여요 | 인박스에서 승인을 기다리는 중일 수 있어요. 자주 쓰는 종류는 자동 승인을 켜세요 |
| AI 실행에서 "API로 실행"이 눌리지 않아요 | 그 AI의 API 키가 서버에 없어요. **앱에서 열기**를 쓰거나 `.env`에 키를 넣고 다시 시작하세요. 이미지·대신 처리는 원래 앱에서만 돼요 |
| 앱에서 열었는데 프롬프트가 비어 있어요 | 프롬프트가 길면 주소에 넣지 않고 복사해 둬요. 입력창에 붙여넣기(⌘V / Ctrl+V) 하세요 |
| Jev 추천이 안 떠요 | `TYPESAFE_API_KEY`가 없거나 호출에 실패하면 규칙으로 추천해요 (화면에 "규칙 판단"으로 표시). 키를 넣으면 "Jev 판단"으로 바뀌어요 |
| 캘린더에 늦게 반영돼요 | 구글 캘린더는 구독 캘린더를 몇 시간마다 새로 읽어요. 급한 건 Hub 화면에서 보세요 |
| 캘린더 주소가 알려졌어요 | 설정 → 캘린더 → **새 주소 만들기** (예전 주소는 바로 막혀요) |
| "요청이 만료됐어요"가 떠요 | 페이지를 새로 고친 뒤 다시 하세요 (오래 열어 둔 화면의 보안 토큰이 바뀐 경우) |
